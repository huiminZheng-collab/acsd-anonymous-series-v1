# Anonymity and publication boundary

This release is **content-anonymous**, not author-unlinkable double blind.
The manuscript and executable fixtures omit natural-person author names, but
the hosting account, repository history, public-key reuse, network activity,
or later disclosure may link the work to its authors.

The public release contains pseudonymous public keys and approvals.  It must
not contain private keys, passphrases, private authorship claims, local user
paths, or hidden identity-bearing metadata.  A key signature establishes
control of that key over exact bytes; it does not by itself establish the
signer's civil identity or historical authorship.

The TeX source is intentionally included in this research release and is part
of the scan surface.  The PDF has an anonymous author block and empty PDF
author metadata.  Repository-account anonymity is not claimed.

Preparing or verifying this directory does not publish it, create a DOI,
submit it to a venue, establish peer review, or grant permission to circumvent
another service's moderation or endorsement rules.  Those are separate
external actions requiring separate authorization.
