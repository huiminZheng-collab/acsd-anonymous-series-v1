# Anonymity statement

Release mode: **content-anonymous**.

- The public package omits author names, email addresses, institutional
  affiliation, ORCID, private keys, and private authorship claims.
- The GitHub account, repository URL, commit metadata, timing, or other public
  context may permit linkage to a person or organization.
- The RFC 3161 evidence establishes an independently signed time bound for the
  manifest digest. It does not establish authorship, novelty, correctness,
  acceptance, peer review, or academic priority by itself.
