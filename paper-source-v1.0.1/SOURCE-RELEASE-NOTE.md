# ACSD v1.0.1 source release

This is an additive source-file release for the already published ACSD v1.0.0
paper. It supplies the TeX source that was omitted from the original public
payload. The scientific PDF, artifact corpus, claims, and verification results
are unchanged; this release does not replace the v1.0.0 manifest or history.

The source is content-anonymous: it contains no author identity claim. The
hosting account and repository remain linkable. The TeX source has been scanned
for identity strings, local paths, private keys, and external inclusions.

This file is source material, not a submission to arXiv or a conference.
