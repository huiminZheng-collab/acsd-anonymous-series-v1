# Anonymity statement

This is a content-anonymous release. The paper, repository files, test keys,
and public metadata intentionally omit author names, affiliations, email
addresses, ORCIDs, acknowledgements, and author-identifying local paths.

This is not an assertion that the authors are unlinkable. In particular, the
hosting account, access logs, publication time, browser fingerprints, Git commit
metadata, a later public key, or prior public work may link the release to an
identity. Users requiring strict double blind should publish from a separately
audited neutral account and follow their venue's current policy.

The release intentionally contains no identity-bound authorship claim and no
private key. A SHA-256 manifest identifies exact public bytes but does not
identify an author or provide trusted time.
